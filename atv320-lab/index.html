محاكي Schneider Altivar Machine ATV320

انفرتر ATV320U40N4C (4 كيلووات، 380–500 فولت 3 فاز، 9.5 أمبير) شغّال على موتور حقيقي. اشتغل من الشاشة المدمجة بأربع أرقام والـ Jog dial زي الجهاز بالظبط، شغّل من أطراف LI بالزراير، غيّر الباراميترات من قوايم rEF و MOn و COnF، اعمل أعطال واعرف تصلحها، وحل التمارين.

تحكم ESC و MODE والـ Jog dial و RUN و STOP بيان الشاشة ولمبات REF/MON/CONF و Value/Unit و CHARGE

  • MODE يلف بين المودات الـ 3: rEF- (المرجع) ثم MOn- (القراءات) ثم COnF (الباراميترات)، واللمبة اللي جنب REF أو MON أو CONF بتقولك انت فين.
  • Jog dial لفه (اسحب في دايرة، أو عجلة الماوس، أو الأسهم وهو متعلّم عليه) عشان تتنقل بين الأكواد أو تغيّر القيمة. اللف السريع بيكبّر الخطوة. دوسة على أي حتة في الطوق تتحرك خطوة، ولو مسكتها تكرر.
  • ENT = تدوس في نص الـ Jog dial (أو Enter). يدخل على القايمة أو الباراميتر، والقيمة ترمش يعني بتعدّل، ودوسة تانية تحفظ. باراميترات زي tCC و CFG و GFS لازم تمسك ENT ثانيتين.
  • ESC يلغي التعديل أو يرجع خطوة لورا.
  • RUN و STOP/RESET: RUN بيشتغل بس لما قناة الأوامر محلية (Fr1 = LCC، أو CHCF = SEP و Cd1 = LCC). STOP بيوقف دايماً لو PSt = YES، ولو فيه عطل اتشال سببه بيمسحه.
