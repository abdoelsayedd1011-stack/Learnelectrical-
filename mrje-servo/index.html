محاكي سيرفو ميتسوبيشي MR-JE-A

درايف MR-JE-40A مع موتور HG-KN43J (400 وات). شغّل من الكيباد (MODE / UP / DOWN / SET)، غيّر باراميترات PA / PB / PC / PD، وصّل إشارات CN1، واتعلّم تقرا إنذارات AL.xx وتصلّحها. وفي آخر الصفحة فرق MR-J4-A.

تحكم أزرار الكيباد بيان الشاشة ولمبة CHARGE

  • MODE يلف على الشاشات: الحالة ‏←‏ التشخيص ‏←‏ الإنذارات ‏←‏ PA ‏←‏ PB ‏←‏ PC ‏←‏ PD.
  • UP / DOWN تختار الباراميتر أو تغيّر الرقم اللي بيرمش.
  • SET تدخل على الباراميتر، وتاني SET تحفظ. وأنت بتعدّل: MODE ضغطة قصيرة تنقل الخانة، وضغطة طويلة تلغي.
  • في شاشة التشخيص على d-01 اضغط SET ضغطة طويلة تدخل JOG، و UP / DOWN مضغوطة تلف الموتور.
