Design Correction on the A3/Speed

1. The idea

The packaging material arrives with the design and the crease lines already printed. The machine pulls the material one package at a time while the jaws seal and cut. If each pull is slightly too long or too short, the print and the crease drift away from the seal and the package comes out looking wrong.

The job of the design control is to make every package exactly the right length, so the crease lands in the right place relative to the jaws.

Register code→Photocells→TMCC→DMC→Servomotor→Cam→Folding flaps

The system does two different things, and you need to keep them apart:

  • Automatic regulation: the card measures the mark position on every package and adjusts the pull by itself to keep the deviation close to zero.
  • Design correction (the offset): a manual setting. It tells the system "treat the correct position as this much higher or lower". You use it when the finished package has the crease in the wrong place although the deviation is zero.

2. Parts and signal path

PartWhat it does
Register codeBlack and white bars printed once per package on the material. It is the reference the system measures against.
PhotocellsRead the code as the material passes and send the reading to the card.
TMCC cardThe brain. It decodes the code, generates the design signal when the code matches, compares its arrival with the machine angle and calculates the required stroke.
Angle encoderTells the card the machine angle at every moment.
DMCThe servo drive. Converts the stroke value into a motor position.
Servomotor and eccentric shaftsThe motor turns the cam, and the cam sets the stroke of the folding flaps.
Folding flapsMounted on the jaws. They add a small extra pull on top of the main pull of the jaws. That extra pull is what the system controls.
PLCGives the card the production angle, volume and speed, and receives the alarms.
The main pull comes from the closed jaw travelling down with the tube. The folding flaps only add a little to it, which is why the system corrects millimetres, not centimetres.

3. Deviation and production angle

The PLC gives the card a value called the production angle: the machine angle at which the mark should pass the photocell.

On every package the photocell fires at the instant the black mark is in front of it, and the card captures the encoder angle at that same instant. The difference between that angle and the production angle, converted to millimetres, is the design deviation.

Deviation = 0        the mark arrived on time
Deviation = +        the mark arrived late (pull too short)
Deviation = -        the mark arrived early (pull too long)
OK window  = ±1.5 mm accepted range in production

While the deviation stays inside ±1.5 mm the Design OK LED is on and packages are accepted. Outside it, packages are rejected and the alarm count starts.

4. Correction and stroke

The card corrects by changing the stroke of the folding flaps. The stroke is a number from Step 0 to Step 999:

SituationWhat the card does
Mark late (positive deviation)Increases the stroke, so the flaps pull more and the next package is longer.
Mark early (negative deviation)Decreases the stroke, so the pull gets shorter.

The correction runs through a PID loop in the card, so it does not happen in one package. It takes a few packages for the deviation to come back close to zero.

There is no single ideal stroke value. It depends on the machine, the material and the speed. What matters is that it is steady and away from both limits. On the card, LED 7 lights when the stroke is above 75% and LED 8 when it is below 25%.

If the stroke sticks at Step 999 or Step 0, the system has used all its range and cannot correct any further. That is not a card fault. It is a sign that something outside needs checking: mechanical setting, material pull, eccentric shafts, the material itself, the jaws or the servo.

5. The offset and the 150-unit example

The card only sees the mark. It does not see the crease itself or the finished package. So the deviation can be zero and the stroke steady while the crease is still high or low on the package, because the distance between the mark and the crease in the material is slightly different.

This is where the design control offset comes in: a value you enter by hand that shifts the target position of the mark.

Offset range   -500 .. +500 units
100 units      ≈ 1 mm
10 units       ≈ 0.1 mm
What you see on the finished packageWhat to do
Crease too highDecrease the offset
Crease too lowIncrease the offset

The classic example

The deviation is close to zero, the stroke is around 160 and the offset is 0, but the crease on the package is 1.5 mm too high. The fix: decrease the offset by about 150 units.

What happens next: the deviation goes slightly negative, the stroke drops for a while, and after a few packages both return close to their old values and the crease is in place.

Do not judge from the first package. Make a small change, wait a few packages for the system to settle, then measure the finished package again.
Why is "high" fixed by decreasing the offset? Because the package is made upside-down in the jaw system: the top of the finished package is at the bottom while it is still in the tube.

6. Start-up and precorrection

On a normal start after a stop, the system continues from the last stroke it was using.

The first start after Tight Tube or Sterile Inching is different: the position of the material relative to the jaws is unknown and the mark can be far away. So the system starts with a phase called precorrection:

  1. The folding flaps stay in the precorrection position, where they have very little effect on the pull.
  2. The machine runs and the mark creeps towards its position package by package.
  3. As soon as the signal comes inside ±10 mm of the target, the system leaves precorrection.
  4. The stroke jumps to Step 0 or Step 999 depending on the direction, corrects quickly towards zero, and then normal regulation takes over.

Packages made during this phase are rejected, which is normal.

7. Servomotor positions

The DMC converts the stroke into a motor position, counted in steps from the mechanical stop:

Home position              400
Precorrection position  18,875
Step 0                  29,000
Step 999                41,750

Production only runs between Step 0 and Step 999. Each stroke unit is about 12.75 motor steps.

If these positions are not reached on the machine (for example homing does not complete correctly), everything after that is wrong even with a healthy card and photocells.

8. The register code

The mark is not a single bar. It is a 26-bit code. The photocells read it as the material moves, and the card compares it with its stored pattern:

11010001111011010001111000

Black = 1 and white = 0. A white-to-black transition = 1, and black-to-white = 0.

A photocell seeing a colour does not mean the code was read. All 26 bits must be read in the right number and order to produce a design signal. That is why other print on the material does not confuse the system, and also why a dirty or misaligned photocell loses the reading.

On the card, LED 1 lights while the code is being read and LED 2 means Design OK.

10. Fault-finding tree

Go through this order before you touch the offset:

  1. Are the photocells reading the code? If not: check the photocells and their cleanliness, the mark itself, the alignment and the wiring.
  2. Is there a design signal? If not: check the decoding, the TMCC card and the stored code pattern.
  3. Is the deviation inside ±1.5 mm? If not: check the timing, the encoder, the material pull, the servo and the PLC data (production angle and volume).
  4. Is the finished package good? If yes: no design correction is needed at all.
  5. If the crease is high: decrease the offset. If it is low: increase it.
What you seeLikely cause
Some packages have the code read wrongDirty photocell
No reading at allPhotocell not aligned to the material
Photocell sees colours but there is no design signalCode pattern does not match the TMCC setting
Deviation jumps in large stepsAngle encoder problem
Deviation oscillatesMaterial slipping or unstable tension
Stroke high or stuck at 999Longer repeat length in the material, or not enough pull
Stroke stuck at Step 0Mechanical setting is off

11. Common mistakes

  • Fixing a fault with the offset. A dirty photocell, slipping material, a stuck stroke or a servo fault are never fixed with the offset. The offset only sets the crease position on a healthy package.
  • Offset from another volume. Every volume has its own offset. If the volume changes and the wrong offset is loaded, the crease is far off although everything works.
  • Judging from the first package. Any change needs a few packages to show.
  • One big change. Change in small steps, 10 or 20 units, and measure.
  • Ignoring the stroke. If the stroke is near either limit, fix the cause first before any adjustment.

12. How to use the simulator

  1. Open the simulator and press "Start". You see the machine from the side: the closed jaw travels down with the tube, and the photocell lights at the instant the black mark passes it.
  2. Try the ready scenarios: normal production, crease 1.5 mm high, start after Tight Tube, dirty photocell, stuck stroke and servo fault.
  3. Change the offset with the buttons under the drawing (0.1, 0.2 and 0.3 mm) and watch the zoomed angle window: the green band moves and the dots follow it.
  4. Watch the chart of the last 150 packages: deviation, crease position and stroke.
  5. Switch on any fault from the list and see the alarms and where the fault-finding tree lights up.
  6. Change the speed, the volume and the mark-to-crease distance, and see where the stroke goes.
