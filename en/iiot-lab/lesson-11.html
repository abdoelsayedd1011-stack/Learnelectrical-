2A typical Node-RED flow

  1. Modbus Read · FC3 · every 1000 ms
  2. Function: names and units
  3. RBE: on change only
  4. MQTT Out · TLS · QoS 1
const r = msg.payload;
msg.payload = {
  ts: Date.now(),
  oven_temp: r[0] / 10,      // 1825 → 182.5 °C
  parts_count: r[1],
  running: (r[2] & 1) === 1,
  current_a: r[3] / 100
};
return msg;

Always add a Catch node and a Last Will "offline".
