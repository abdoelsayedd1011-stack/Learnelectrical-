PROFINET

Almost every new Siemens panel runs PROFINET. The secret is the device name: set the names correctly and draw the topology, and TIA Portal will tell you which cable is in the wrong port.

1What is the difference between PROFIBUS and PROFINET?

PROFINET is the PROFIBUS idea on Ethernet: a Controller exchanges data with Devices. But each device is identified by a name and an IP instead of an address number.

It has three channels. RT with a 1–10 ms cycle for I/O and VFDs. IRT with a 250 µs cycle for motion control, which needs special switches. And TCP/IP, not deterministic, used for configuration and diagnostics.

2Why the name first, then the IP?

Because the Controller looks for the device by its name, then gives it an IP address. The steps: add the GSDML file and enter the name and IP in TIA. Then run Assign device name on the device itself. Then download the project to the CPU.

The name: lowercase letters, digits and hyphens only, like vfd-line3. Replaced a device? Give it the same name.

3How are the devices connected?

In a line, any break loses everything after it. In a star each device connects to a managed switch, which is safer. In an MRP ring the network survives one break and recovers within 200 ms.

Use industrial switches that support PROFINET. LLDP reveals a cable plugged into the wrong port.

4What do the LEDs tell you?

BF steady: no link or no Controller. BF flashing: the device is there but has no data, so check the name and IP, and is it configured in the project?

SF: a missing module or a broken wire. And the yellow MT: a cable is dropping frames and needs maintenance.

In TIA open the Diagnostics buffer. The free tool PRONETA scans the network.

5What are the common PROFINET mistakes?

A new device doesn't appear: its name is not set or has a capital letter. BF flashes after a replacement: the device carries an old name, so reset it and set the name. Drops out every few minutes: a duplicate IP, or a cable next to a VFD.

Everything after one point disappeared: a line topology with a broken cable. And IRT doesn't work: an ordinary switch in the path, or a topology that differs from the project.
