Modbus TCP

If you understand Modbus RTU, you already understand 90% of Modbus TCP. The rest is an IP address, a small header and a few traps such as word order.

1The same idea, over Ethernet

Modbus TCP is Modbus RTU itself (the same four tables and the same function codes), but instead of a twisted pair and a CRC, the request is sent inside a TCP connection on port 502. So there is no baud rate, no parity and no terminating resistor: the two devices simply need to be on the same IP network.

2The MBAP header

Every request is preceded by a 7-byte header called the MBAP:

00 0100 0000 060103 00 6B 00 02
Transaction IDProtocol ID (always 0)Remaining lengthUnit IDPDU: function and registers
  • Transaction ID: a number that increments with each request, so the client can match every response to its request when it sends several at once.
  • Unit ID: used when the server is a gateway converting TCP to RTU: it carries the address of the serial slave behind the gateway. For a native Ethernet device, set 1, 255 or 0 as the manual specifies.

3Reading a PLC from a laptop

Most modern PLCs can act as a Modbus TCP server: Siemens S7-1200 (with the MB_SERVER block), Schneider M221/M241 (built in), Delta, Omron and others. The register map varies: on Schneider, %MW0 starts at register 0; on Siemens, a DB is designated as the holding-register area.

  1. Confirm the laptop can see the PLC (ping).
  2. Open a client program (such as Modbus Poll or QModMaster) pointed at the PLC's IP and port 502.
  3. Select function 03, address 0, quantity 10, with a poll cycle of 1000 ms.
  4. If you get Connection refused: the server is not enabled in the PLC program, or a firewall is blocking the port. If you get a Timeout, the problem is the network (Lesson 2).
32-bit values: many values (production counter, power) occupy two registers. Word order varies: big-endian (high word first) or little-endian. If you read a huge, meaningless number, swap the two words.

4Performance and limitations

  • A 100 ms poll cycle for dozens of registers is routine on Ethernet, but Modbus TCP is not deterministic: never use it for emergency stops or axis synchronization.
  • Read contiguous registers in a single request (up to 125 registers) rather than ten small requests.
  • The number of simultaneous connections is limited (for example, 8 on some PLCs). An HMI + SCADA + gateway + your laptop can exhaust them, and the new connection is refused.
  • Modbus has no encryption and no password: any device on the network can write registers. Isolate the machine network from the office network (Lesson 11).

5The Modbus TCP ⇄ RTU gateway

When the drive is serial and the SCADA is on Ethernet, you install a gateway: on one side an RS-485 port with three drives (addresses 1, 2 and 3), on the other a single IP address. The client sends a TCP request with Unit ID = 2; the gateway converts it into an RTU frame for slave 2 and returns its response. A timeout here usually originates on the serial side (Lesson 3).
