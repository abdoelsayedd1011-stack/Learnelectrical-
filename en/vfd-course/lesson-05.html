Control terminals

The keypad is fine for testing, but in a plant the drive takes its orders from the terminals: a selector, a push button or a PLC to run, a pot or an analog signal for speed, and it answers through a relay that says «I'm running» or «I've tripped». You will wire all of this and run it yourself.

1Digital inputs (DI)

Each digital input is programmed for a function (in the parameters): run forward, run reverse, stop, preset speed, reset, external fault… An input turns on when it receives 24 V from the terminal supply (in PNP / source mode), or when it is connected to 0V (in NPN / sink mode). A jumper, switch or parameter sets which.

MethodHowNote
2-wireA selector (maintained contact): closed = run, open = stopIf power returns with the selector closed, the motor can start by itself. Careful!
3-wireA momentary Start button (NO) + a Stop button (NC), and the drive latches itselfLike a seal-in circuit in classic control. Safer after a power cut
Preset speeds: two digital inputs give you 4 speeds: 00 = speed from the analog input or the first preset, 01 = preset 1, 10 = preset 2, 11 = preset 3. For example, a conveyor that runs slowly while loading and fast while transferring.

2The speed signal (AI)

  • Potentiometer (usually 10 kΩ): one end to +10V, one end to 0V/ACM, and the middle terminal (wiper) to AI. If speed goes up the wrong way, swap the two outer ends.
  • 0–10 V from a PLC: easy, but affected by noise and distance.
  • 4–20 mA: the best for long distances, and the drive can detect a broken wire (below 4 mA). Make sure the input is set to current, not voltage (switch or parameter).

3Outputs: relay and analog

  • Relay (dry NO/NC contact): programmed as fault, run, ready or «at speed». It can carry a small 230 V AC load for a lamp or a PLC input.
  • Analog output (0–10 V or 4–20 mA): sends speed or current to a meter or to the PLC.
  • STO (Safe Torque Off): two safety inputs that cut torque in hardware. They usually have a factory jumper, and if the jumper is removed the drive will not run.

4Wire it and run it

Run → DI1, direction → DI2, pot → AI1, lamp → relay. Then test it below.
