VFD course

Before you touch any drive's keypad, understand what it does. In this course you will see how a drive works inside, wire the power and control yourself, set the basic parameters from the motor nameplate, brake a heavy load without an OV trip, run a pump on PID, and diagnose faults like a field technician. The explanation is general for every brand, and afterwards you practise on the simulator of the device that matters to you.

Before you start: this course assumes you understand the 3-phase motor, star and delta connections and a simple start circuit. If not yet, start with the classic control course → and come back here.

How to study here

  1. Read the explanation: one idea per part, in plain words
  2. Try it in the simulator: start a motor, wire terminals, cause an OV fault yourself
  3. Do the drills: calculations, wiring and fault finding
  4. Answer the questions so the lesson is marked complete

Lessons in order, each lesson builds on the one before

    After the course: practise on the device simulators with the same keypad and terminals: PowerFlex, SINAMICS, Altivar, ABB, Delta and more.
