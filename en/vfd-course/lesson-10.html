Common faults and fixes

Every drive talks to you with a fault code. The code is not the fault itself, it is the symptom: OC means the current went over the limit, but why? In this lesson you learn to read the code, gather the facts, and find the real cause before you press Reset.

1Before the reset

  1. Write down the code and look at the fault history: when did the fault happen? What were the current, frequency and DC bus at that moment? (Most drives store them.)
  2. Ask: did it happen during accel? During decel? While running steady? As soon as power came on?
  3. Check what the code points to (cable, motor, supply, ventilation, a parameter).
  4. Fix the cause, then reset. If resetting has become a daily routine, the problem is still there.
Do not keep resetting an OC or ground fault. Every time you start into a short you damage the IGBTs more. Switch off and test the cable and motor with a megger (after disconnecting them from the drive).
