This is a training simulator, not the original software. The screen is modelled on the Delta software (ISPSoft and WPLSoft) and a DVP-14SS2 so the real thing feels familiar: the addresses (X0 · Y0 · M0 · T0 · C0) and the instruction names follow Delta. But this is not Delta software and it does not talk to a real PLC.

1What you will see in the Delta software

Input · output · memoryX0 · Y0 · M0. X and Y numbers are octal: after X7 comes X10 (there is no X8 or X9). The DVP-14SS2 has X0–X7 and Y0–Y5
ContactsLD / AND / OR for NO, LDI / ANI / ORI for NC, and LDP / LDF for edges
OutputOUT Y0 · SET Y0 · RST Y0; in the diagram they appear in brackets [ SET Y0 ]
Timer and counterTMR T0 K50: T0–T199 count in 100ms units, so K50 = 5 seconds. CNT C0 K10 is reset with RST C0
CompareLD= · LD> · LD>= … such as LD>= C0 K5
High-speed counterC251 counts an A/B encoder on X0 and X1 (32-bit): it runs with DCNT C251 K10000, is compared with DLD>= / DAND<, and is reset with RST C251
RunningWrite to PLC → RUN switch → Ladder Monitor (the active contact is highlighted)
