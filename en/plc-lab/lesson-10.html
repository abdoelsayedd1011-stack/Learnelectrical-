▶ The lesson in 5 minutes

Illustrated explanation, the simulator task solved, and the quiz answered. Made for the phone.

1Where do I look for the fault?

Go from the outside in, in order. First look at the CPU: is it in RUN? Is an ERROR or FORCE light on?

Then the input LEDs: if an input doesn't light, the problem is the wire, the sensor or the supply. Then open the program online and see at which contact the green stops.

Finally the output LEDs: if the output is lit but the contactor isn't pulled in, the problem is the fuse, the wire or the coil.

The green colour in the simulator on RUN is the same as online mode on a real PLC, and it is the top troubleshooting tool.

2What is forcing?

Forcing means you force an input I or output Q to 1 or 0, whatever its real state. We use it to test an output or to bypass a faulty sensor for a moment.

Forcing an output really switches the load and bypasses interlocks. Make sure nobody is near the machine, and remove it as soon as you finish.

In the simulator: press Force, then tap an I or Q LED: first tap 1, second 0, third removes it. Try Force 1 on Q0.0.

3Fix the programs

Each program here has a classic mistake. Put it in RUN and test, then fix it until the test passes.

Simulator: programs with faults

The three mistakes are: double coil, the same coil in two rungs so only the last rung wins, and the fix is one rung per coil. Wrong NC, the machine never runs, and the fix is to write Stop and the overload as NO in the program.

And wrong seal-in, the machine stops by itself or won't stop, and the fix is to put the Q contact in parallel with Start only.

4Faults you meet on site

FORCE light is on: a forgotten force, check the force table first. The program on the laptop differs from the PLC: do an Upload or Compare before any change.

Machine keeps stopping at the same place: a sensor working at its limit, use the Trace. And the fault appeared after changing a card: check the hardware configuration.
