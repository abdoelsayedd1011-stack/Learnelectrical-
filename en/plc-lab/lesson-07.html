Memory, flags and edges

In a relay panel you added an auxiliary relay to remember something or to get extra contacts. In a PLC this is called an M memory bit, and you have thousands of them. You will also learn the most important tool in real programs: the edge, which makes something happen only once at the moment of change.

1M memory bits

M0.0, M0.1… are bits inside the CPU that are not connected to any terminal. You write them with a coil and ask about them with contacts, exactly like an auxiliary relay, but with no wire and no cost. We use them as flags: "the machine is in automatic mode", "an alarm happened", "step 2 is active".

Retentive or not? Normal bits are cleared when the power goes off or the PLC goes to STOP. There is a retentive area that remembers its value. Make important counters (today's production) retentive, but not run commands.

2Edges: rising and falling

P (rising edge) ↑: it conducts for one scan only at the moment the bit changes from 0 to 1, even if it stays 1 for an hour.
N (falling edge) ↓: it conducts for one scan at the moment the bit changes from 1 to 0. For example, "the can has just passed the sensor".

Why does it matter? The scan repeats hundreds of times per second. If you want to do something once per press (count, toggle a state, move to the next step), you need an edge. Otherwise it happens in every scan while the button is held.

4Exercise: an alarm with memory

A high-pressure switch may trip for a moment and reset. If the lamp is on only while the switch is active, nobody will see it. The fix: a flag that remembers the alarm happened until the operator acknowledges it.

5Common faults on site

Common program faults:
  • The lamp flickers or stops in a random state: a toggle without an edge. The state flips every scan while the button is held.
  • The same M bit is used for two things: someone wrote M0.0 in a new part of the program although it was already used. Keep a table of the M bits in use and name them.
  • An edge does not work in TIA: the same edge memory bit is used in more than one P contact. Each edge needs its own memory bit.
  • The machine continued from where it was after the power came back: the step bits were retentive. Think about each bit: should it be cleared or kept?
