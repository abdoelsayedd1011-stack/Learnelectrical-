This is a training simulator, not the original software. The screen is modelled on TIA Portal and a CPU 1214C so the real software feels familiar when you open it: the addresses (%I0.0 · %Q0.0 · %M0.0 · %IW64) and the instruction names follow Siemens. But this is not Siemens software and it does not talk to a real PLC.
