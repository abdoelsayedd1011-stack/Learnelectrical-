Your first Ladder program

Ladder looks like a ladder: two side rails (the power) with rungs between them. Each rung has conditions (contacts) on the left and a result (coil) on the right. If "power" can flow from left to right, the coil turns on. Simple, but there is a famous trap you will fall into and climb out of in this lesson.

1The contact and the coil

NO contact -| |-

"Ask: is this bit 1?" If it is 1, it conducts. It does not have to be an NO button in real life; it is a question about the bit.

NC contact -|/|-

"Ask: is this bit 0?" If it is 0, it conducts; if it is 1, it opens.

Coil -( )-

It writes the bit: 1 if power reaches it, 0 if it does not. It is always at the end of the rung, on the right.

The key idea: a contact in the program is not a real wire. It looks at a bit in memory (is I0.0 1 or 0?). You can ask about the same bit with NO in one rung and NC in another, as many times as you like.

2AND and OR

AND = series: two contacts one after the other. The coil turns on if both are 1.
OR = parallel (branch): two contacts side by side. The coil turns on if either one is 1.

How to make a branch in the simulator: tap the contact on the main line and choose "⫴ Parallel branch for this cell". A second row appears below it with a new contact connected on both sides. Choose its address and you are done. You can also control the vertical links yourself with the "Link left-up" and "Link right-up" buttons.

3Simulator: AND and OR

Exercise 1: the press runs only when the operator presses with both hands (safety). Exercise 2: a stair light that turns on from either switch. Write the program, press RUN and try it with the switches, then press "Test program": the simulator tries every combination for you.

4The trap: the NC-wired Stop button

In real life the Stop button is wired NC (closed while nobody presses it). Why? So that if the wire breaks, the machine stops by itself (fail-safe). So while nobody presses it, the PLC sees I0.1 = 1. When you press it, it becomes 0.

Wrong: "The button is NC, so I'll use an NC contact in the program." Result: the bit = 1 all the time, so the NC contact is open all the time, and the motor will never start.
Right: an NO contact on I0.1. Bit = 1 (nobody pressing) → it conducts. Stop pressed → bit 0 → it opens. If the wire breaks → 0 → it opens too.
The rule: in the program you ask about the state in which you want to run. An NC-wired Stop is 1 in the normal state → ask about it with NO. The same applies to the NC overload contact (95–96) and every protection device.

6Common faults on site

Common program faults:
  • The motor does not start and the program "looks right": an NC contact in the program for an NC-wired Stop button or overload. Open the monitor and look: is the contact green or not?
  • A branch is not connected on one side: a parallel branch is missing its vertical link on one side, so the lower contact does nothing. The simulator shows this with the green power flow.
  • Wrong address: you wrote I0.1 instead of I0.2. Give every address a name (symbol / tag) so mistakes are easy to see.
