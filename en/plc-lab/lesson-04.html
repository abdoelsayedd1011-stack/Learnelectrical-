Seal-in and Set/Reset

The Start button is pressed and released, but the motor must keep running. In classic control we did this with an auxiliary contact of the contactor. In a PLC it is exactly the same idea, but in the program. We will also see another method with Set and Reset, and how to stop a motor from running forward and reverse at the same time.

1Seal-in (latch)

🔒A Q0.0 contact in parallel with Start holds the circuit after you release the button. Same as the seal-in lesson.

  1. Start ⇒ Q0.0 = 1
  2. Q0.0 contact closes
  3. Release Start: keeps running
  4. Stop ⇒ I0.1 = 0 ⇒ drops out
Stop and overload go on the main line after Start joins Q0.0, or the latch keeps holding.

3Set and Reset

Set -(S)-Makes the bit 1 and keeps it
vs
Reset -(R)-Returns it to 0
The last rung wins: put Reset after Set so stop has priority. The NC Stop is checked with NC here (reset when the bit = 0).

4Interlock: forward and reverse

⛔KM1 and KM2 together = a phase-to-phase short. Each output gets an NC of the other.

In the panel, repeat the interlock with NC auxiliary contacts in case a contactor welds.
