Seal-in and Set/Reset

The Start button is pressed and released, but the motor must keep running. In classic control we did this with an auxiliary contact of the contactor. In a PLC it is exactly the same idea, but in the program. We will also see another method with Set and Reset, and how to stop a motor from running forward and reverse at the same time.

1Seal-in (latch)

The same DOL circuit as in the auxiliary relay and seal-in lesson: a contact of the output itself (Q0.0) in parallel with the Start button. As soon as the motor starts, that contact holds the circuit even when you release the button.

  1. Press Start → I0.0 = 1 → power flows → Q0.0 = 1.
  2. In the next scan, the Q0.0 contact (the lower one) is now closed.
  3. Release Start → power still flows through the Q0.0 branch → the motor keeps running.
  4. Press Stop (wired NC) → I0.1 = 0 → its NO contact opens → Q0.0 = 0 and the seal-in drops out.
Why is Stop before the seal-in and not after it? Stop and the overload must be on the main line after the point where Start and Q0.0 join, so they cut both. If you put Stop inside the Start branch only, the seal-in keeps holding and the motor will not stop.

3Set and Reset

Another method: a Set coil -(S)- makes the bit 1 and it stays 1 even when the condition goes away. A Reset coil -(R)- sets it back to 0. So Set and Reset have their own "memory" without a seal-in.

Who wins if both are active? The PLC runs from top to bottom, and the last rung that writes the bit wins. So if you put Reset after Set, stop has priority (which is what we want for safety). Note: here we ask about the NC-wired Stop with an NC contact, because we want to Reset when the bit = 0 (someone pressed it).

4Interlock: forward and reverse

A motor turns in both directions with two contactors, KM1 (forward) and KM2 (reverse). If both turn on together → a phase-to-phase short circuit. The fix: each output has an NC contact of the other output (interlock). In the panel the same interlock is also made with NC auxiliary contacts of the contactors themselves, in case a contactor welds.

5Common faults on site

Common program faults:
  • The motor stops as soon as you release Start: the seal-in is missing, or its branch is not connected on both sides.
  • The motor does not stop with Stop: Stop is inside the Start branch only, or Reset is before Set while Start is still pressed.
  • The motor restarted by itself when the power came back: the bit was retentive (kept through a power loss) and used with Set. Motors must need a new Start after the power returns.
  • The forward and reverse contactors were both on for a moment: there is no interlock in the program or in the wiring, or the direction was changed without a pause.
