Allen-Bradley · Studio 5000 style

In Allen-Bradley there are no addresses in the program: everything is a tag with a name like Start_PB, a contact is called XIC, and a timer counts in milliseconds and gives you .DN. Here you will create tags, download and turn the key, just like a real controller. 9 exercises, including cut-to-length with an encoder and a high-speed counter card, and the last one is an automatic warehouse door challenge.

This is a training simulator, not the original software. The screen is modelled on Studio 5000 Logix Designer and a CompactLogix 1769-L33ER controller so the real software feels familiar: the tags and the instruction names (XIC · XIO · OTE · TON · CTU) follow Allen-Bradley. But this is not Rockwell software and it does not talk to a real PLC.

1What you will see in Studio 5000

TagsEverything has a name in the Controller Tags. Inputs and outputs are aliases to the card: Start_PB → Local:1:I.Data.0. Rungs are numbered from 0
Contacts and coilsXIC = NO · XIO = NC · OTE coil · OTL / OTU = Set / Reset · ONS = one shot (edge)
TimerTON / TOF / RTO with a tag of type TIMER: Preset and Accum in milliseconds (5 seconds = 5000), and the bits .EN, .TT and .DN
CounterCTU / CTD on a tag of type COUNTER; .DN when ACC ≥ PRE, and RES resets it
Compare and analogEQU · NEQ · GRT · GEQ · LES · LEQ, and SCP converts the card reading (4000–20000 = 4–20mA) to a percentage
High-speed counterThe encoder on a high-speed counter card: the count is a tag of type DINT (Enc_Count on Local:4:I.Ch0Count), reset with an OTE on the bit Local:4:O.Ch0Reset, and compared with GEQ / LES as usual
RunningGo Online → Download → Run Mode, or turn the key RUN · REM · PROG. In Run the active instruction lights green
