Control modes

A servo can run in position, speed or torque mode, or execute positions stored inside it. In this lesson you will try each mode yourself on a simulator and learn to read the pulse formats.

The mode is set by a parameter (and sometimes you can switch between two modes with an input). The names differ: Delta, for example, calls them PT, PR, S and T, and other manufacturers use other names, but the idea is the same.

Notice: in torque mode the motor does not control the speed. If the load is suddenly removed (the material breaks) it will run up to the speed limit, so you must always set it.

3Pulse formats

  • Pulse + Direction: one wire for the pulses and one for the direction (high = forward, for example). The most common with a PLC.
  • CW / CCW: one pulse wire for each direction.
  • A / B (quadrature): like an encoder, 90° apart. Used when a servo follows the encoder of another machine.

The drive must be set to the same format the PLC outputs (the pulse format and logic parameter). If it is not set correctly, the motor may turn in one direction only, not turn at all, or move half the distance.
