الانفرتر بيطلع من المصنع وعليه جمبر بين 01 و 11، وجمبر بين S1 و S2 و S+. هنا مكانهم زرار STOP (مقفول NC، دوسة تعلّقه ودوسة تفكه) وريليه الأمان. في 2-Wire (المصنع) زرار RUN FWD ثابت: دوسة تقفل 02 ودوسة تفتحه، وسلكتور 03 = Run REV. لو t062 = 3-Wire Start يبقى الزرار لحظي، و 03 يبقى اتجاه. الإيثرنت والـ PLC بيشتغلوا لما P046 = 5 أو P047 = 15. دبل كليك على أي مقبض يصفّره.

تمارين محلولة: التوصيل والباراميتراتتحكم
