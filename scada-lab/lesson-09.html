الوصفات والسكربتات

وصفة واحدة صحيحة تغيّر الخط من منتج إلى آخر في ثوانٍ. والسكربت الصغير يضيف ذكاءً إلى الواجهة دون أن يأخذ دور الـ PLC.

‹ الدروسالمحاكي

1ما الوصفة؟ ولماذا نحتاجها؟

📋الوصفة = قيم منتج كاملة تُرسل إلى الـ PLC دفعة واحدة.

البنيةالعناصر + الوحدة + الحدود
السجلقيم منتج واحد
الهدفDB بنوع UDT مطابق
  • حجم التعبئة1000 · 500 · 250 ml
  • سرعة التعبئة80 · 70 · 60 %
  • عزم الغطاء180 · 150 · 120 N·cm
  • زمن الخلط240 · 240 · 180 s

في Unified اسمها Parameter Sets وتُعرض في Parameter Set Control.

2تحميل الوصفة إلى الـ PLC بأمان

  1. تحقّق الحدود
  2. Line_Running = 0
  3. اكتب في Buffer
  4. Req ← الـ PLC تتحقق وتنسخ ← Done
الـ PLC خط الدفاع الأخير: ترفض أي قيمة خارج المدى مهما كان مصدرها.
  • تحميل أثناء التشغيلأحجام مختلطة ← شرط التوقف + المصافحة
  • وحدات مختلفة1 ml بدل 1 L
  • UDT تغيّرقيم منزاحة ← حدّث البنية
  • من غيّر الوصفة؟صلاحية المهندس + سجل التدقيق

3سكربتات JavaScript في WinCC Unified

📜السكربت داخل حدث، والمشترك في وحدة عامة.

let vol = Tags("Filler_Volume_SP").Read();
if (vol < 200 || vol > 1050)
  HMIRuntime.Trace("refused " + vol);
else Tags("Line_Start_Cmd").Write(true);
  • افعلقصير وسريع · وحدة عامة · سجّل بـ Trace
  • لا تفعلحلقات انتظار · نسخ الكود · تعشيقات أمان

ابدأ بالوظائف الجاهزة. Ignition: Python. Optix: C#.

4المهام المجدولة

  • وقت ثابت06:00 تصدير تقرير الوردية
  • دوريكل 10 دقائق متوسط زمن الدورة
  • تغيّر وسمتسجيل اسم الوصفة الجديدة
  • إنذارفتح شاشة الضاغط تلقائيًا
العدّادات وتصفيرها في الـ PLC، لا في مهمة على الشاشة.

5كيف تعرف أين المشكلة؟

  • Req لم يرتفعالمشكلة في الـ HMI
  • Req بلا Doneالـ PLC رفضت القيم
  • قيمة في عنصر آخرالبنية لا تطابق الـ UDT
  • السكربت لا يعملTrace viewer: اسم وسم خطأ
  • المهمة لم تُنفَّذتوقيت الخادم والمنطقة الزمنية
على المحاكي: جرّب قيمة خارج المدى، ثم التحميل والخط يعمل، ثم أوقفه وحمّل. افتح المحاكي ←
