تحكم الستة زراير وبكرة الكيباد (اسحبها لفوق ولتحت) بيان الشاشة ولمبات RUN و STOP و FWD و REV و PLC ولمبة CHARGE

  • MODE ضغطة قصيرة تلف على الشاشات: F أمر السرعة ← H تردد الخرج ← U شاشة المستخدم (00-04) ← A التيار ← Frd/rEu الاتجاه ← PLC ← الباراميترات 00-. جوه الباراميترات بيرجع مستوى لورا.
  • MODE ضغطة طويلة (ثانية تقريبًا): تشغّل أو تقفل الشيفت، يعني تعدّل خانة خانة. الخانة اللي بترمش هي اللي بتتغير.
  • ▲ يزوّد، و ◄/▼ يقلّل. في الشيفت: ▲ يزوّد الخانة اللي بترمش و ◄ ينقل للخانة اللي على الشمال. امسكهم عشان يسرعوا.
  • ENTER يدخل على الجروب ثم الباراميتر ثم القيمة، وفي القيمة يحفظ ويكتب End. لو القيمة مرفوضة يكتب Err.
  • RUN تشغيل لما 00-21=0. STOP/RESET إيقاف، ولو فيه عطل يمسحه.
  • البكرة اللي جنب الشاشة بتبقى مصدر السرعة لما 00-20=7.
