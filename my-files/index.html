ملفاتي

الصفحة دي ليك انت بس. ارفع أي ملف بأي حجم، وخد لينك تبعته لأي حد. اللي معاه اللينك بس هو اللي يقدر ينزّل الملف. وأدوات الـ PDF بتاعتك هنا: تعديل PDF.

محتاج تفعّل مكان التخزين مرة واحدة

  1. ادخل dash.cloudflare.com ← R2 Object Storage ← Create bucket، وسمّيه my-files.
  2. ادخل Workers & Pages ← مشروع learnelectrical ← Settings ← Bindings ← Add ← R2 bucket.
  3. في Variable name اكتب FILES، واختار الـ bucket اللي عملته، واحفظ.
  4. اعمل Retry deployment لآخر نشر (أو استنى أي تحديث جاي للموقع)، وبعدين افتح الصفحة دي تاني.
